# Adventure Game

Un juego de aventura textual desarrollado con JavaScript y Node.js.

## Descripción

Adventure Game es un juego interactivo basado en texto donde el jugador puede introducir su nombre y tomar decisiones durante una aventura.

El proyecto forma parte de mi aprendizaje de JavaScript y programación.

## Tecnologías utilizadas

- JavaScript
- Node.js
- readline-sync
- Git
- GitHub
