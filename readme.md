# Adventure Game

Un juego de aventura textual desarrollado con JavaScript como parte del aprendizaje de fundamentos de programación.

## Descripción

**Adventure Game** es un juego interactivo basado en texto en el que el jugador puede introducir su nombre y tomar decisiones durante una aventura.

El proyecto fue desarrollado utilizando **JavaScript** y ejecución desde Node.js.

## Tecnologías utilizadas

* JavaScript
* Node.js
* readline-sync
* Git / GitHub

## Cómo ejecutar el proyecto

1. Clona el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Entra a la carpeta del proyecto:

```bash
cd AdventureGame
```

3. Instala las dependencias:

```bash
npm install
```

4. Ejecuta el juego:

```bash
node AdventureGame.js
```

## Ejemplo

```text
Welcome to the Adventure Game
Prepare yourself for an epic journey!

What is your name, adventurer?
```

El jugador puede introducir su nombre y comenzar la aventura.
